# dengueriskcdmx: Data, Rasters and Code for the Dengue Transmission Risk Map of the Mexico City Metropolitan Area

Data, rasters and code supporting the dengue transmission risk map of
the Mexico City Metropolitan Area. Includes the Aedes aegypti ovitrap
presence and pseudo-absence data with nine environmental and
socio-demographic predictors (2017-2024, with training and test
partitions), the external validation data (2025), the study area, and
the Quarto code of the machine-learning workflow (in the vignettes).
Also provides, in 'inst/extdata', the rasters (about 500 m) of the
probability of Aedes aegypti occurrence, the probability of confirmed
imported dengue cases, and the five-level epidemiological risk map, all
derived from the consensus (mean of the probabilities) of Random Forest,
LightGBM and XGBoost models.
