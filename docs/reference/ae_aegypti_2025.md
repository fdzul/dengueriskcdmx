# Aedes aegypti external validation data, 2025

Ovitrap presences and pseudo-absences from 2025, not used to fit or tune
the models. Used for the external validation. Temperature and elevation,
which are not predictors of the primary scenario, are not included.

## Usage

``` r
ae_aegypti_2025
```

## Format

An `sf` object with the same columns as
[ae_aegypti_2017_2024_train](https://fdzul.github.io/dengueriskcdmx/reference/ae_aegypti_2017_2024_train.md).
